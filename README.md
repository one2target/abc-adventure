# ABC Adventure · Alfie

Английские буквы A–F для детей 4–7 лет. Готовые аудиозаписи, короткие задания и одежда для жирафика. Без библиотек, установки и сборки.

[Открыть тренажёр](https://one2target.github.io/abc-adventure/) · [Репозиторий](https://github.com/one2target/abc-adventure)

## Запуск

На iPhone откройте ссылку в Safari. Для ярлыка: **Поделиться → На экран «Домой» → Добавить**. На Android или компьютере используйте обычный браузер. Нажмите **START / CONTINUE**; звук начинает работать после касания. Интернет нужен для загрузки онлайн-версии и её медиа. Service Worker и гарантированный офлайн-кеш не предусмотрены.

Для локального запуска распакуйте **весь архив**, сохранив структуру, и откройте `index.html` на компьютере. Для проверки через HTTP: `python3 -m http.server 8765 --directory outputs` из папки проекта. На iPhone используйте опубликованную ссылку: просмотрщик «Файлы» может не исполнять JavaScript.

## Учебный маршрут

- Каждая буква: заглавная/строчная → название и звук → слово → найти букву → выбрать картинку → узнать букву по картинке.
- Три освоенные связи дают звезду. Ошибки сохраняются отдельно и увеличивают частоту повторения слабой буквы; отложенная очередь возвращает её в подходящей игре.
- После A–C — мини-игра из пяти заданий, затем выбор куртки.
- После D–F — мини-игра из пяти заданий, затем выбор головного убора.
- В конце — десять заданий с обязательным присутствием всех пяти типов, включая строчные буквы.

**👕** открывает гардероб. После завершения блока доступны оба варианта его подарка. Одежду можно менять сколько угодно. **🔊 / 🔇** переключает звук; **Послушать** повторяет всю инструкцию с буквой или словом. Домик возвращает на главный экран, сохраняя позицию.

**Parents**: удерживайте две секунды либо нажмите и ответьте на вопрос для взрослого. Поддерживаются клавиатура, Escape и возврат фокуса. Внутри — ответы, ошибки, mastery и сброс с подтверждением.

## Файлы

- `index.html` — существующая учебная механика, CSS, конфигурации персонажа и наград, экраны и события.
- `audio-manager.js` — единый проигрыватель и отменяемые последовательности.
- `assets.js` — каталог реальных имён файлов: 60 MP3 и 5 PNG.
- `audio/` и `images/` — предоставленные исходные файлы без изменений содержимого.
- `manifest.webmanifest`, `icon-*.png`, `.nojekyll` — ярлык и статическая публикация.
- `TESTS.md` — проведённые проверки; `UPDATE-REPORT.md` — подробности изменений и ограничения исходных изображений.

Папки изначально назывались `audio:` и `images:`. Убраны только двоеточия в названиях папок. Новые изображения и звук не создавались.

## Озвучка

Инструкции и похвала воспроизводятся русскими MP3. Названия букв, фонемы и слова — английскими MP3. Между частями инструкции пауза 500 мс. Один Audio-объект используется повторно; новое действие останавливает старую очередь. Повтор воспроизводит последнюю инструкцию целиком, похвала её не затирает. Переход после правильного ответа ждёт окончания короткой похвалы и связи «буква — слово».

SpeechSynthesis используется только при отсутствии/ошибке загрузки записи и с соответствующим языком (`ru-RU` либо `en-US`). Отказ браузера в autoplay не включает синтетическую замену. При нормальной загрузке файлов TTS не вызывается. Звук не отправляется во внешние API.

## Персонаж и награды

`renderCharacter()` создаёт один DOM-контейнер с пропорциями 1024 × 1536 и слоями изображений. Все слои масштабируются вместе. `characterConfig.layers` задаёт порядок: backpack → base → shoes → jacket → neck → headwear → handItem → special. Положение задаётся долями общего холста в `characterConfig.categories[category].rect`; уже совмещённые будущие PNG могут использовать `[0, 0, 1, 1]`.

Предоставленные изображения имеют разные масштабы, поэтому для курток и головных уборов настроено размещение целого изображения в общем холсте. Сам PNG не обрезается, не перекодируется и не фильтруется. **Базовый PNG имеет непрозрачный тёмный фон**, который сохранён. Исходники не являются идеально совмещёнными слоями; для точного совпадения всех контуров в будущем нужны зарегистрированные прозрачные слои на общем холсте.

`rewardConfig` связывает завершённый блок букв, категорию и варианты предметов. `itemCatalog` строится из этой конфигурации. Новые категории/награды добавляются через данные, без изменения обработчиков выбора. G–Z пока не добавлены.

## Сохранения и миграция

Ключи сохранены: `alfie-abc-v1` и отдельный `alfie-abc-demo-v1`. Внутренняя версия данных стала `2`; **новых ключей localStorage нет**.

Добавлены поля:

- `characterState.unlockedItems`, `characterState.equipped`;
- `completedBlocks`, `claimedRewards`;
- `rewardFlow` — незавершённый показ/выбор награды и способ возвращения в учебный маршрут.

Загрузка старой версии сохраняет статистику, очередь повторений, выбранный вопрос и позицию. Завершение блока определяется по позиции после мини-игры; одна только mastery не выдаёт подарок. Если блок уже пройден в старой версии, предложенный выбор одежды не заменяет учебную позицию. После выбора обучение продолжается с прежнего места.

Выбор одежды сохраняется сразу, до анимации. Перезапуск до выбора вновь открывает подарок; после выбора — подтверждение с кнопкой «Дальше». Уже полученная награда повторно не навязывается. Полный сброс обнуляет обучение, одежду и награды, сохраняя настройку звука.

Прогресс хранится на этом устройстве в этом браузере. Синхронизации между устройствами нет. Сохранения локального файла не переносятся автоматически на домен GitHub Pages.

## Обновление

GitHub Pages публикует корень ветки `main`. Обновляйте HTML, оба JS и папки медиа вместе, сохраняя относительные пути. При добавлении медиа выполните `python3 work/build-assets.py` из локального проекта, чтобы обновить `assets.js`. Этот скрипт только читает файлы и создаёт каталог.

`?demo=1` включает отдельное тестовое сохранение и сокращает паузу визуального перехода. Все учебные задания остаются настоящими, награда по-прежнему требует выбора предмета. `DEBUG = true` включает диагностику проигрывания и наград; при `false` остаются только предупреждения о не загрузившихся файлах.
