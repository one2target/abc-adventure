# ABC Adventure · Alfie

Автономный тренажёр английских букв для детей 4–6 лет.

## Запуск по ссылке

[Открыть ABC Adventure](https://one2target.github.io/abc-adventure/)

[Репозиторий](https://github.com/one2target/abc-adventure)

Откройте ссылку в Safari на iPhone, Chrome на Android или браузере компьютера. Аккаунт GitHub для игры не нужен. Нажмите **START**, разрешения на микрофон или камеру не требуются.

### На iPhone

1. Откройте ссылку именно в Safari.
2. Нажмите **Поделиться → На экран «Домой»**.
3. Оставьте название **Alfie ABC** и нажмите **Добавить**.
4. Запускайте игру через появившуюся иконку.

Интерфейс учитывает вырез экрана и нижнюю панель iPhone, поддерживает вертикальное и горизонтальное положение. На компьютере доступны мышь, Tab, Enter и пробел.

Для загрузки онлайн-версии нужен интернет. Service Worker не используется; ярлык не гарантирует запуск без сети. Озвучка использует установленный английский голос устройства.

### Прогресс

Прогресс и звук сохраняются автоматически в данном браузере. На другом телефоне или компьютере будет отдельный прогресс; автоматической синхронизации нет. Сохранения локального HTML не переносятся на GitHub Pages автоматически. Очистка данных браузера или приватный режим могут удалить сохранение. Если запись недоступна, игра покажет сообщение и продолжит работать в памяти.

### Локальный запуск

Можно по-прежнему открыть `index.html` на компьютере двойным щелчком. HTML содержит всю игровую логику и стили; установка, npm и сборка не нужны. `manifest.webmanifest` и `icon-*.png` нужны для ярлыка, но не для прохождения уроков.

На iPhone приложение «Файлы» может показывать HTML в Quick Look без работающего JavaScript. Для iPhone используйте онлайн-ссылку в Safari.

## Публикация и обновления

GitHub Pages публикует корень ветки `main`. В репозитории находятся:

- `index.html` — приложение;
- `manifest.webmanifest` — параметры ярлыка;
- `icon-180.png`, `icon-192.png`, `icon-512.png` — иконки;
- `.nojekyll` — публикация статических файлов без Jekyll;
- `README.md` и `TESTS.md` — инструкция и проверки.

Для обновления откройте репозиторий, выберите **Add file → Upload files**, загрузите изменённые файлы и нажмите **Commit changes**. Ссылка останется прежней. После успешной публикации в разделе **Actions** перезагрузите страницу тренажёра. При изменении только уроков достаточно заменить `index.html`.

## Учебный маршрут

- A, B, C: знакомство с заглавной/строчной буквой → слово → найти букву → буква/картинка → картинка/буква.
- Мини-игра: 5 заданий по A–C.
- D, E, F: тот же маршрут и ещё 5 заданий по D–F.
- Финальная игра: 10 заданий всех пяти типов, включая строчные буквы. Каждый тип обязательно встречается.
- Три успешных связи дают звезду и деталь ракеты. Исправленный после ошибки ответ тоже засчитывается; ошибки сохраняются отдельно.
- Трудные буквы получают больший вес. Очередь возвращает их через несколько вопросов в ближайшей игре, где эта буква входит в набор. Ошибка в последнем вопросе может повториться в следующей игре.

**🔊 / 🔇** — включить/выключить звук. **☆** — посмотреть ракету и звёзды. **Домик** — вернуться на старт с сохранением позиции. **Parents** — удерживайте 2 секунды; на клавиатуре сфокусируйте кнопку и удерживайте Enter или пробел. При коротком нажатии можно ответить на простой вопрос для взрослого — это также позволяет войти с клавиатуры без удерживания. Там видны связи, ответы и ошибки; сброс всегда требует подтверждения во внутреннем окне.

## Картинки и робот

Дополнительные файлы не обязательны. При желании создайте рядом с HTML папки `images/` и `audio/`.

В массиве `letters` замените `image: null`, например, на:

```javascript
image: 'images/apple.webp'
```

Поддерживаются PNG, WebP и другие браузерные форматы. Квадратное изображение с прозрачным фоном подходит лучше всего. При ошибке загрузки останется emoji. Робота заменяйте через `ALFIE.image`, например `images/alfie.webp`.

## Звук и фонемы

Нажатие **START / CONTINUE** активирует звук. До взаимодействия озвучки нет. **Listen** повторяет реплику. При отсутствии Speech Synthesis игра остаётся доступной визуально; наличие английского голоса и его работа без интернета зависят от устройства.

Web Speech API не гарантирует правильное произношение отдельной фонемы. Поэтому без MP3 приложение предлагает услышать начальный звук внутри слова: «Listen to the first sound in apple. Apple». IPA на экране служит подсказкой взрослому; его не отправляют синтезатору как обычный текст.

Для точной фонетики запишите короткие звуки без добавочного «uh» после согласных и укажите пути в соответствующей записи `letters`:

```javascript
letterAudio: 'audio/a-name.mp3',   // название буквы: /eɪ/
soundAudio: 'audio/a-sound.mp3',   // звук в Apple: /æ/
wordAudio: 'audio/apple.mp3'       // слово Apple
```

Остальные звуки: B /b/, C /k/, D /d/, E /ɛ/, F /f/. При указанных путях приложение сначала пробует запись, затем использует английский синтез речи. `null` означает, что файл не настроен: лишних запросов и ошибок загрузки при обычном запуске нет. При повреждённом/отсутствующем настроенном файле загрузка прерывается по тайм-ауту и включается fallback. Браузер при этом может написать диагностическое сообщение о файле в своей консоли.

Функции `speak`, `playAudio`, `playLetterName`, `playLetterSound`, `playWord` отделены от экранов. При смене экрана или выключении звука предыдущая речь отменяется.

## Добавление букв

Добавьте объект в `letters`, например:

```javascript
{
  letter: 'G', lowercase: 'g', sound: 'g', name: 'jee',
  word: 'Game', emoji: '🎮',
  color: '#7961ad', tint: '#f0eafa',
  image: null, letterAudio: null, soundAudio: null, wordAudio: null,
  distractors: ['C', 'O']
}
```

`name` — подсказка синтезатору для названия, `sound` — IPA, `distractors` — необязательные альтернативы в первом задании. Буквы должны быть уникальны; слово должно начинаться с указанной буквы и звука. Группы по 3, сохранения, статистика и финальная игра обновятся автоматически. Неполная последняя группа использует только доступные ответы (без дубликатов). Первые шесть звёзд собирают шесть частей ракеты; следующие добавляются в общий прогресс. Если к завершённому курсу добавить буквы, обучение продолжится с первой новой буквы.

## Деморежим и отладка

Добавьте `?demo=1` к адресу файла, например `index.html?demo=1`. Появится кнопка «Следующий этап», а задержки сократятся. Деморежим использует отдельный ключ сохранения и не затрагивает детский прогресс. Для обычной игры уберите параметр.

В исходнике есть `const DEBUG = false;`. Значение `true` включает диагностические сообщения. Код разделён комментариями на данные, хранение, звук, вопросы, экраны и управление.

Сводка выполненных проверок находится в `TESTS.md`. Проверка мобильной ширины в настольном браузере не заменяет проверку физического iPhone и его установленного английского голоса.
