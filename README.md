# ABC Adventure · Alfie

Английские буквы A–F для детей 4–7 лет: короткие задания, готовая озвучка и подарки для жирафика.

[Открыть тренажёр](https://one2target.github.io/abc-adventure/) · [Репозиторий](https://github.com/one2target/abc-adventure)

## Запуск

На телефоне или компьютере откройте ссылку и нажмите START / CONTINUE. На iPhone в Safari можно добавить ярлык: Поделиться → На экран «Домой». Для локального запуска распакуйте весь архив и откройте index.html на компьютере либо запустите HTTP-сервер из outputs. Для онлайн-версии нужен интернет; гарантированный офлайн-кеш не предусмотрен.

## Обучение и подарки

Порядок уроков сохранён: название и звук буквы → слово → три задания на узнавание. После A–C идёт мини-игра из пяти вопросов и выбор **одной куртки**. После D–F — ещё пять вопросов и **один аксессуар**: букет или шарик. Финальная игра содержит десять вопросов всех пяти типов, включая строчные буквы.

Выбранный подарок сразу принадлежит ребёнку и появляется на главной странице. Второй вариант остаётся закрытым. Значок 👕 открывает коллекцию: полученный предмет отмечен галочкой, альтернативный показан с замком и недоступной кнопкой. Покупка за звёзды пока не реализована.

🔊 / 🔇 управляет звуком. «Послушать» повторяет текущую инструкцию. Домик возвращает на главный экран и сохраняет место в уроке. Parents открывает статистику для взрослого: удерживайте две секунды или ответьте на контрольный вопрос. Сброс очищает обучение и подарки, сохраняя настройку звука.

## Изображения

В assets.js подключены девять предоставленных PNG:

- background_home.png и background_reward.png — учебная и праздничная сцены;
- giraffe_base.png, giraffe_jacket_stars.png, giraffe_jacket_racer.png — полные варианты жирафика;
- accessory_bouquet.png и accessory_balloon.png — прозрачные слои поверх жирафика;
- reward_icon_jacket_stars.png и reward_icon_jacket_racer.png — изображения только для карточек выбора.

Все девять изображений предзагружаются. renderCharacter() создаёт общий контейнер 2:3: фон снизу, один полный жирафик в общей области персонажа, аксессуар над ним. Область персонажа и аксессуар масштабируются вместе, без отдельных поправок для разных устройств. object-fit: contain сохраняет пропорции. Карточки отдельно кадрируют пустые поля иконок средствами CSS, не изменяя PNG.

Старые jacket_01/02 и headwear_01/02 сохранены в папке как исходные файлы, но не подключаются к приложению и не предзагружаются. Куртки больше не накладываются на тело отдельным слоем.

## Сохранения

Ключи localStorage прежние: alfie-abc-v1 и alfie-abc-demo-v1. Общая версия сохранения остаётся 2. Для наград добавлено rewardStateVersion: 2.

characterState содержит ownedItems и equipped: giraffeVariant (base / jacket_stars / jacket_racer), handItem (null / accessory_bouquet / accessory_balloon). completedBlocks, claimedRewards и rewardFlow сохраняют завершённые блоки, полученные награды и незавершённый выбор. Массив ownedItems допускает будущие дополнительные способы получения вещей; покупки в текущем коде нет.

При переносе старых данных сохраняется только выбранная куртка: jacket_01 → jacket_stars, jacket_02 → jacket_racer. Ошибочно открытая альтернатива закрывается. Прежние головные уборы заменены новым выбором аксессуара без повторения уровня. Учебная позиция, mastery, ошибки, вопрос, очередь повторения и mute сохраняются. Выбор до анимации записывается одним сохранением. Повторное или быстрое второе нажатие не меняет подарок. Перезагрузка до выбора восстанавливает предложение, после выбора — подтверждение.

## Озвучка и код

60 прежних MP3 остаются в каталоге. Русские инструкции и английские записи, очередь, паузы 500 мс, repeat, mute и fallback не изменены. Для подтверждения нового аксессуара используется существующее 27_new_item.mp3. audio-manager.js не менялся.

index.html содержит исходное обучение и обновлённые сцены, конфигурацию наград, владение предметами и миграцию. assets.js генерируется из реальных файлов командой python3 work/build-assets.py из корня локального проекта. GitHub Pages публикует корень main. Обновляйте код и медиа вместе, сохраняя относительные пути.

?demo=1 использует отдельное тестовое сохранение; все задания и условия наград остаются настоящими. DEBUG по умолчанию false. Проверки описаны в TESTS.md, изменения — в UPDATE-REPORT.md.
