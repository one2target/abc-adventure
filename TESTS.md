# Проверки обновления с жирафиком — 12 сентября 2026

## Полный сценарий в браузере

Выполнен через видимые кнопки в локальной HTTP-версии, с отдельным сохранением `?demo=1`:

1. START → знакомство с A → слово → три задания.
2. Намеренно неверный ответ: мягкая реакция, то же задание; после перезапуска сохранены позиция и ошибка.
3. A, B, C → пять вопросов ABC mini challenge → экран курток.
4. Перезагрузка до выбора возвращает экран подарка.
5. Выбор `jacket_01`: предмет выделен, появился слой куртки, «Дальше» доступно после анимации.
6. D, E, F → пять вопросов DEF mini challenge. Куртка `jacket_01` сохранена.
7. Выбор `headwear_02`: одновременно видны base + jacket_01 + headwear_02.
8. Перезагрузка после выбора сохраняет подарок и открывает подтверждение.
9. Гардероб: jacket_01 → jacket_02; headwear_02 → headwear_01. Перезагрузка сохранила оба слоя.
10. Финальные десять заданий, включая lowercase, пройдены. Parent View показал **39 попыток, 38 правильных ответов, 1 ошибку; mastery 3/3 у всех шести букв**.
11. Полный сброс после завершения удаляет одежду и открытые категории; жираф снова без одежды. Mute сохранён.

## Аудио в браузере

- После включения звука проигрывается `03_new_letter.mp3`; последовательность заканчивается `apple.mp3`, ошибка media element отсутствует.
- Повтор запускает русскую инструкцию заново; быстрый повтор использует тот же единственный элемент audio.
- Mute немедленно останавливает плеер; unmute повторяет инструкцию.
- Загрузившиеся изображения имеют `naturalWidth > 0`; в консоли приложения ошибок/предупреждений не обнаружено.

## Автоматические регрессионные проверки

Команда в локальном проекте: `node work/verify-giraffe.cjs`. Итог — PASS.

Проверены:

- все 38 правильных ответов полного маршрута, обе мини-игры и final;
- выдача двух подарков, разблокировка обоих вариантов, постоянная экипировка;
- загрузка незавершённого выбора и выбранного подарка до нажатия «Дальше»;
- отсутствие повторной обязательной выдачи;
- отсутствие подарка за mastery без пройденной мини-игры;
- миграция v1 в середине урока и после полного курса с сохранением статистики;
- возврат к старой учебной позиции после выбора мигрированной награды;
- reset, сохранение mute, недоступный localStorage;
- повторное нажатие на ответ, перезапуск во время перехода;
- очередь слабых букв, 500 проверок уникальности ответов, 40 проверок покрытия типов final;
- расширение учебных данных дополнительной буквой без добавления её в выпускаемый курс;
- последовательность файлов и паузы не меньше 500 мс, повтор всей инструкции;
- отмена во время паузы, быстрые касания, mute;
- один переиспользуемый Audio-объект, максимум один одновременно активный;
- ноль вызовов TTS при доступных записях;
- fallback отсутствующей записи с правильным языком, отсутствие TTS при блокировке autoplay;
- безопасная ошибка картинки одежды и одно предупреждение вместо повторяющихся;
- удерживание кнопки Parent View две секунды.

## Медиа и размеры экранов

- Все 60 MP3 распознаны системным `afinfo`; ошибок формата не обнаружено.
- SHA-256 всех 65 исходных медиа совпадает с инвентаризацией: файлы не изменены.
- В браузере проверены 390×844, 320×568, 844×390 и 1280×900. Горизонтального переполнения нет.
- Обёртки base, jacket и headwear имеют одинаковые размеры и координаты на телефоне и компьютере; размеры изображений внутри задаются долями общего холста.
- Проверены обе куртки и оба головных убора. Для исходников с разными масштабами использована общая конфигурация размещения.
