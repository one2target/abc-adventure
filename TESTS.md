# Проверки обновления наград · 13 сентября 2026

## Автоматические проверки

Запуск из корня проекта: node work/verify-reward-ownership.cjs. Результат — work/reward-ownership-test-results.json, passed: true.

- Два полных прохождения по 38 ответов: A–C, mini 5, D–F, mini 5, final 10; mastery всех букв 3/3.
- Сценарий A: jacket_stars + accessory_balloon. Сценарий B: jacket_racer + accessory_bouquet. В каждом случае принадлежат только две выбранные вещи.
- Закрытые альтернативы не надеваются через equipItem; второй вызов chooseReward, в том числе сразу после первого, отклоняется.
- Reload до выбора и после выбора, обязательная награда не повторяется, незавершённый выбор сохраняется.
- Старые v1-сохранения и прежняя v2 с обеими unlockedItems: перенос выбранной куртки, закрытие альтернативы, новый выбор аксессуара вместо головного убора. Статистика и позиция совпадают до/после миграции. Повторная миграция не выдаёт вещи.
- Промежуточные сохранения с новыми именами предметов и без нового маркера версии.
- Reset очищает ownedItems, экипировку, claimedRewards и pending flow; mute сохраняется.
- Ошибка localStorage сохраняет работоспособность в памяти; сохранение в середине задания и защита двойного ответа.
- Взвешенные повторения, 500 наборов неповторяющихся вариантов, 40 проверок покрытия типов финальной игры.
- Последовательности аудио с паузами 500 мс, repeat, cancel, mute, отмена во время паузы, один аудиообъект и не более одного одновременно играющего файла. Нормальный сценарий без TTS, корректные языки fallback, отказ autoplay не вызывает TTS.
- Родительский доступ по удержанию 2 секунды; отсутствие картинки не ломает интерфейс.

## Проверки через браузер

Оба сценария пройдены на отдельном demo-сохранении через обычные кнопки заданий, без подмены состояния или обхода mini challenge.

Сценарий A: чистый старт → A–C + mini → reload незавершённой награды → звёздная куртка → reload выбранной награды → домой и в коллекцию → D–F + mini → reload → шарик → reload → финальные 10 вопросов. На главной отображаются background_home, giraffe_jacket_stars и accessory_balloon. Гоночная куртка и букет disabled.

Сценарий B: сброс с подтверждением → базовый жирафик на домашнем фоне, mute сохранён → A–C + mini → гоночная куртка → D–F + mini → букет → reload → финальные 10 вопросов. На главной отображаются background_home, giraffe_jacket_racer и accessory_bouquet. Звёздная куртка и шарик disabled.

На обоих праздниках используется background_reward; на первом карточки содержат отдельные reward_icon_jacket изображения. Повторный выбор закрытого предмета отсутствует и после reload. PNG загружаются, звук 03_new_letter.mp3 проигрывается без ошибки. Консоль без JavaScript ошибок и предупреждений.

## Верстка и неизменность исходников

Проверены 320 × 568, 390 × 844, 844 × 390 и 1280 × 900. Ширина страницы совпадает с viewport; персонаж и аксессуар имеют одинаковые прямоугольники размещения. Главная, обе награды и коллекция проверены визуально. На коротких экранах используется обычная вертикальная прокрутка.

Данные букв, генерация вопросов, mastery, статистика, учебные переходы и основной загрузчик прогресса сравнены с резервной копией и совпадают. Все предоставленные PNG и audio-manager.js проверены по SHA-256 без изменений. Каталог по-прежнему содержит все 60 MP3.

Физический iPhone/iOS Safari недоступен для теста; браузерная проверка размеров его не заменяет.
